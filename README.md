# 清潔公司派車系統

Django 版本。

## 啟動

PowerShell：

cd E:\Python\cleaning_dispatch

.\.venv\Scripts\Activate.ps1

python manage.py runserver

網站：

http://127.0.0.1:8000/

Admin：

http://127.0.0.1:8000/admin/

## 建立管理員

python manage.py createsuperuser

## 功能

- 儀表板
- 客戶管理
- 車輛管理
- 人員管理
- 清潔案件
- 派車管理
- 派車單列印
- Django Admin
- SQLite
